# 🚀 آزمایشگاه جنگو | پایه نهم

به کلاس کدنویسی جنگو خوش آمدی! اینجا یک محیط **واقعی** پایتون و جنگو داری؛ برای اجرای کدها به نصب نرم‌افزار روی گوشی یا کامپیوترت نیازی نیست.

> 🧑‍💻 خودت نام پروژه، اپلیکیشن، صفحه‌ها و طراحی سایت را انتخاب می‌کنی. فایل‌های ساخته‌شده در Explorer قابل مشاهده و ویرایش هستند.

## ۱. پروژه شخصی خودت را بساز

از استاد لینک مخزن قالب را بگیر. در گیت‌هاب روی **Use this template → Create a new repository** بزن و مخزنت را با نام دلخواه بساز. سپس **Code → Codespaces → Create codespace on main** را انتخاب کن.

این محیط هنگام اولین راه‌اندازی، جنگو را خودکار از `requirements.txt` نصب می‌کند. چند لحظه صبر کن تا آماده شود.

## ۲. ترمینال را باز کن

از منوی **Terminal → New Terminal** استفاده کن. دستورها را **دقیقاً** در ترمینال وارد کن؛ نیازی نیست در پنل هوش مصنوعی سمت راست چیزی تایپ کنی.

### دستور اول: ساخت پروژه

```bash
django-admin startproject mysite .
```

- `startproject` یعنی ایجاد ساختار پروژه جنگو.
- `mysite` فقط یک مثال است. **نام پروژه را خودت انتخاب کن** (انگلیسی، بدون فاصله).
- نقطه `.` مهم است: فایل‌های پروژه در همین پوشه کلاس ساخته می‌شوند.

### دستور دوم: آماده‌سازی آموزشی پروژه

```bash
python classroom.py prepare
```

این ابزار فقط تنظیمات لازم را انجام می‌دهد و در ترمینال توضیح می‌دهد چه چیزهایی تغییر کرده‌اند:

- اپ `classroom_tools` به `INSTALLED_APPS` در `settings.py` اضافه می‌شود.
- پوشه `templates` به تنظیمات قالب‌ها اضافه می‌شود.
- نمایش سایت در پنجره Codespaces برای حالت آموزشی تنظیم می‌شود.
- کلید توسعه به مقدار مخصوص **آزمایش** تغییر می‌کند؛ برای انتشار واقعی مناسب نیست.

### دستور سوم: ساخت اپلیکیشن

```bash
python manage.py startapp shop
```

`shop` یک اسم نمونه است. می‌توانی اسم اپ را به دلخواه انتخاب کنی. در این کلاس دستور واقعی `startapp` اجرا می‌شود و **پس از ساخت اپ، ابزار آموزشی مراحل اضافه را کامل می‌کند**:

| فایل/پوشه | اتفاقی که می‌افتد |
|---|---|
| `shop/` | ساخت پوشه اصلی اپ با دستور استاندارد جنگو |
| `settings.py` | ثبت نام اپ در `INSTALLED_APPS` |
| `shop/templates/shop/index.html` | ساخت اولین صفحه HTML |
| `shop/views.py` | تعریف تابع `index` برای نمایش صفحه |
| `shop/urls.py` | اتصال آدرس به تابع `index` |
| `mysite/urls.py` | اتصال آدرس‌های اپ به پروژه |

**این مراحل را در ترمینال می‌بینی؛ حتماً فایل‌های مربوطه را از Explorer باز کن و تغییرات را پیدا کن.**

نکته: برای فعال‌بودن ابزار آموزشی، دستور اپ را با `python manage.py startapp` اجرا کن؛ `django-admin startapp` به تنهایی همان دستور استاندارد جنگوست.

### دستور چهارم: اجرای سایت

```bash
python manage.py runserver 0.0.0.0:8000
```

روی اعلان **Open in Browser** برای پورت `8000` بزن؛ یا از زبانه **Ports** لینک پورت ۸۰۰۰ را باز کن. اولین اپ در آدرس اصلی `/` باز می‌شود.

اگر خواستی سرور را متوقف کنی، در ترمینال کلیدهای **Ctrl+C** را بزن.

## ۳. یک صفحه جدید بساز

```bash
python manage.py newpage shop about
```

این دستور برای اپ `shop`، صفحه `about.html` و View و URL مربوط به آن را می‌سازد. اسم `shop` و `about` را می‌توانی تغییر بدهی. صفحه را در آدرس `/about/` ببین (اگر `shop` اولین اپ توست).

اگر اپ دومی بسازی، آدرس پیش‌فرض آن با نام اپ شروع می‌شود؛ مثلاً `/news/`.

## ۴. با پایگاه داده کار کن

```bash
python manage.py migrate
```

این دستور جدول‌های اولیه جنگو را در پایگاه داده آزمایشی SQLite ایجاد می‌کند. برای آموزش و تمرین کافی است؛ برای انتشار سایت عمومی، تنظیمات پایگاه داده را جداگانه بررسی می‌کنیم.

## ۵. کارت را برای جلسه بعد ذخیره کن

```bash
git add .
git commit -m "My Django project"
git push
```

**فایل‌های کد** با این سه دستور در مخزن گیت‌هاب ذخیره می‌شوند و از دستگاه دیگر هم قابل دریافت‌اند. فایل `db.sqlite3` عمداً در گیت ذخیره نمی‌شود؛ اطلاعات آزمایشی آن را نسخه دائمی سایت حساب نکن.

برای جلوگیری از مصرف سهمیه، وقتی کارت تمام شد از صفحه [Codespaces](https://github.com/codespaces) محیطت را **Stop** کن. برای جلسه بعد دوباره از همان صفحه آن را باز کن.

> ⚠️ Codespaces محل *تمرین و برنامه‌نویسی* است، نه هاست دائمی سایت. وقتی محیط خاموش شود، سایت آزمایشی هم از دسترس خارج می‌شود. مرحله انتشار واقعی را بعداً انجام می‌دهیم.

## 📱 اگر با گوشی کار می‌کنی

- در Chrome وارد گیت‌هاب شو؛ در صورت نیاز **Desktop site** را فعال کن.
- گوشی را افقی بگیر تا ترمینال و فایل‌ها بهتر دیده شوند. صفحه روی موبایل کوچک است و تایپ با صفحه‌کلید خارجی می‌تواند آسان‌تر باشد.
- کدها و نقطه و کوتیشن را دقیق بنویس. برای اجرای کد حتماً به اینترنت نیاز داری.

## 🎯 تمرین آزاد

یک موضوع دلخواه انتخاب کن: معرفی کتاب‌ها، باشگاه ورزشی، فروشگاه کوچک، گردشگری، یا معرفی خودت. پروژه، اپ و دو صفحه بساز؛ متن و رنگ‌های صفحه را با سلیقه خودت تغییر بده. لینک مخزن و لینک پیش‌نمایش را طبق دستور معلم ارائه کن.
